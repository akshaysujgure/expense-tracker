# Telegram setup
## Create bot
1. Open BotFather
2. Run `/newbot`
3. Save the bot token
## Add bot to the family/group
1. Add the bot to the Telegram group
2. Make sure the bot has the needed permissions for the Mini App
## Configure Mini App
Set the Mini App URL to the GitHub Pages URL.
## Security note
Do not create any application-side family enrollment flow. The Telegram group/chat itself defines the family scope.
